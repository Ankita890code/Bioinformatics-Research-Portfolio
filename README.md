## Research Projects

### 01. In-Silico Drug Repurposing for Alzheimer's Disease
**M.Sc. Dissertation Project**

Investigation of potential FDA-approved BACE1 inhibitors through a multi-stage computational drug discovery workflow.

**Key approaches:**
- Virtual screening of FDA-approved compounds
- Molecular docking using Glide
- ADMET profiling
- Molecular dynamics simulation
- Protein–ligand interaction analysis

**Tools:** Schrödinger Maestro, LigPrep, Glide, Desmond, SwissADME

[View Repository →](https://github.com/Ankita890code/in-silico-drug-repurposing-for-alzheimers-disease)


### 02. 3D Field-Based QSAR Analysis of BACE1 Inhibitors
**M.Sc. Third-Semester Minor Project**

Development of a field-based 3D-QSAR model to investigate the relationship between molecular features and BACE1 inhibitory activity.

**Key approaches:**
- Dataset retrieval and preprocessing
- IC50 to pIC50 conversion
- K-means clustering
- Ligand alignment
- 3D Field-Based QSAR modelling
- PLS-based model development

**Tools:** Schrödinger Maestro, LigPrep, Canvas, BindingDB, PubChem

[View Repository →](https://github.com/Ankita890code/field-based-qsar-bace1-inhibitors-minorproject-third-semester)


### 03. Structural Analysis of PDE3B in the Context of Androgenic Alopecia
**M.Sc. Second-Semester Micro Project**

Computational investigation of Human Phosphodiesterase 3B (PDE3B), using its crystal structure (PDB ID: 1SO2), and analysis of protein–ligand interactions.

**Key approaches:**
- Protein structure retrieval and validation
- Structural superimposition
- Ligand preparation
- Molecular docking
- Binding-pocket and interaction analysis

**Tools:* Schrödinger Maestro, Swiss-PdbViewer, PyMOL, PubChem

[View Repository →](https://github.com/Ankita890code/androgenic-alopecia-pde3b-1so2-analysis-m.sc-microproject-second-semester)
